# GERENCIAMENTO MAGICO

Aplicação web simples para gerenciamento de entradas no estilo Masaniello.

## Configuração inicial padrão

- Banca inicial: **100**
- Número de operações: **7**
- Meta de win: **2**
- Odd média: **2.0**

## Como usar

1. Abra o arquivo `index.html` no navegador.
2. Clique em **Iniciar ciclo**.
3. Registre cada operação com os botões grandes **WIN** ou **LOSS**.
4. O sistema sugere automaticamente a próxima entrada.

## Observação

A lógica foi inspirada na organização de ciclo da planilha Masaniello, distribuindo risco por operações restantes e ajustando a entrada sugerida para perseguir meta de lucro no ciclo.
